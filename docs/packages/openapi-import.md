# `@xapps-platform/openapi-import`

Reusable transformer from OpenAPI specs to Xapps manifest structure.

## Purpose

- Parse JSON/YAML OpenAPI documents
- Generate manifest tool/widget baseline from operations
- Reuse import logic across CLI and API routes

## Runtime

- Node.js tooling/backend

## Key exports

- `buildManifestFromOpenApiText`
- `buildManifestFromOpenApiDocument`
- `extractOpenApiInfoFromText`
- `slugifyManifestName`
